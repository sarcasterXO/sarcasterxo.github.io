# Sarcaster

The personal website of Aarya Chavan, aka [sarcasterXO](https://github.com/sarcasterXO), built with the Next.js 16 App Router. The public repository is [github.com/sarcasterXO/sarcasterxo.github.io](https://github.com/sarcasterXO/sarcasterxo.github.io), and the site URL is [sarcaster.is-a.dev](https://sarcaster.is-a.dev). It is a static export hosted on GitHub Pages. There is no database, auth, or server.

## Stack

- Next.js 16.4 and React 19, App Router at the repo root. No `src/` directory.
- TypeScript 6.0.3. Typecheck with `tsc` through `bun run typecheck`. Do not use `bun check`.
- Bun 1.4.4. `packageManager` is pinned. Install with `bun install`.
- Tailwind CSS 4 through `@tailwindcss/postcss`. There is no `tailwind.config`.
- shadcn style `base-rhea` on Base UI. One component exists: `components/ui/button.tsx`.
- `motion`, `react-icons`, and `three` are installed for later use. Do not add a demo just to import them.
- Oxlint and Oxfmt, both extending `@imranbarbhuiya/oxc-config`. Oxlint is type-aware.

## Layout

```
app/layout.tsx          Root layout, Inter, `metadata` and `viewport`
app/page.tsx            Home page: bio, current work, and links
app/not-found.tsx       404 page with a link home
public/robots.txt       `/robots.txt`: allow `/`
app/globals.css         Tailwind and shadcn theme tokens
app/favicon.ico         Site icon
public/me.jpg           Avatar used on the home page
public/.well-known/     Discord domain verification
components/ui/          shadcn components
components.json         shadcn CLI config
lib/utils.ts            Re-exports `cn` from the `cn` package
next.config.ts          `output: 'export'` and unoptimized images
oxlint.config.mts       Lint config
oxfmt.config.mts        Format config
postcss.config.js       Tailwind PostCSS plugin
tsconfig.json           `@/*` maps to the repo root. `incremental` is false
.github/workflows/      GitHub-hosted CI and the GitHub Pages deploy
.github/husky/          commit-msg and pre-commit hooks
.github/problemMatchers tsc problem matcher for CI annotations
.vscode/settings.json   Oxc as formatter and fixer, workspace TypeScript
.vscode/extensions.json Recommends the Oxc and Tailwind CSS extensions
```

`next build` writes `.next` and the static site in `out`. `output: 'export'` rules out anything that needs a server: request-time data, Server Actions, the default image optimizer, Cache Components, Partial Prefetching, and route handlers other than `GET` with `force-static`. Read `node_modules/next/dist/docs/01-app/02-guides/static-exports.md` before adding them. `next-env.d.ts` is generated by `next typegen` and ignored by git. Do not turn incremental compilation back on. That writes `tsconfig.tsbuildinfo`.

The home page is left-aligned: name and bio, current work, then contact and social links. The `work` and `links` arrays in `app/page.tsx` hold that content. The theme is light and muted. `color-scheme` is `light`. Do not add a dark-mode toggle.

`app/layout.tsx` sets `title.template` to `%s | Sarcaster`, so a page exports `title: 'Name'`, not the full title. `name` and `description` constants feed `metadata`, `openGraph`, and `twitter`. `metadataBase` is `https://sarcaster.is-a.dev`. There is no Open Graph image and no sitemap, so `public/robots.txt` has no `Sitemap` line. `viewport.themeColor` is `#e5ecf3`, the hex of `--background`. Change both together.

Buttons that render an `<a>` must set `nativeButton={false}`. Internal links use `render={<Link href="/" />}`, as in `app/not-found.tsx`. Base UI otherwise warns that it expected a `<button>`.

## Commands

- `bun run dev` starts the app.
- `bun run preflight` formats, typechecks, lints with fixes, and builds.
- `bun run lint:check` and `bun run format:check` report without writing.
- `bun run build` writes the production site to `out`. `next start` does not work with a static export, so preview `out` with any static file server.

CI on GitHub-hosted `ubuntu-latest` runs `lint:check`, `format:check`, and `typecheck` for pushes to `main` and for pull requests. CI does not run commitlint; only the local `commit-msg` hook does. CI does not run `next build`, so run `bun run build` locally before pushing changes that touch rendering or config.

`.github/workflows/deploy.yml` builds `out` and deploys it to GitHub Pages on pushes to `main` or a manual run. The `github-pages` environment only allows `main`. The upload step sets `include-hidden-files` so `public/.well-known/discord` is published. Do not remove it. The custom domain is set in the repository's Pages settings, so there is no `CNAME` file.

## Conventions

- Add shadcn components with `bunx shadcn add <name>`. `components.json` sets `iconLibrary` to `lucide` so the CLI stays valid. `lucide-react` is not installed. Use `react-icons`. If a generated file imports `lucide-react`, replace that import and remove the package.
- Oxlint sorts JSX props alphabetically. `className` comes before `lang` and before `data-slot`.
- Commit messages follow Conventional Commits. The `commit-msg` hook runs commitlint.
- The `pre-commit` hook runs lint-staged: Oxfmt on staged files, then Oxlint `--fix` on staged JavaScript and TypeScript, including `jsx` and `tsx`.
- `plans/` is historical, gitignored, and ignored by Oxlint and Oxfmt. Fresh clones do not have it. Do not restyle it while changing the site.
